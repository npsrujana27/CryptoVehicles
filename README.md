This is a major project me and my team have done during our bachelors degree

Used solidity, Blockchain to develop this communication to reduce the number of single points of failure, and vulnerability
to cyberattacks and to increase the scalability. 

This project explains the use of blockchain technology in VANETs to provide efficient security, real-time establishment of trust, 
and efficient transaction processing. Based on the use of smart contracts, CryptoVehicles provides self-executing contracts
for secure data exchange, payment automation (for example tolls, parking, and charging), and reputation management.
This proposed approach aims to enhance vehicular network security, efficiency, and privacy and further drive 
next-generation intelligent transportation systems.
